# The CAN messages the firmware itself uses. Consumed by tools/gen_dbc.py to emit
# main/can/dbc/dbc_generated.{c,h}.
#
# Columns (whitespace separated):  NAME  BUS  ROLE
#   BUS  = 0 (chassis / party) or 1 (vehicle) -- the physical bus the frame
#          rides on, i.e. which MCP251xFD instance receives it.
#   ROLE = decode : firmware decodes this message's signals on-device (full
#                   signal table emitted -- costs flash). Its frames get an
#                   exact filter into the fast-lane FIFO (at most 28 per bus).
#          filter : not decoded; only forwarded to an app that has not sent its
#                   own CAN filter list. Not needed by current DashPilot.
#
# Every NAME must exist in dbc/bus_1_tesla_vehicle.dbc.
# Keep decode entries tight: every decoded message costs flash.
#
# What the app gets is the app's business: DashPilot writes the ids its
# decoder reads to the CAN filter characteristic, any number on either bus,
# and only those are forwarded. They need no entry here.
